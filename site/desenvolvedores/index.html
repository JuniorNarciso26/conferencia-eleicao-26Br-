Contribuir com a coleta

Escolha uma zona eleitoral e receba um roteiro de coleta feito para ela. O portal preenche os códigos eleitorais e orienta você da instalação até o Pull Request.

A coleta roda no computador Linux/WSL ou VPS. Antes de começar, reserve a zona por 24 horas com seu login GitHub.

JÁ INICIOU UMA COLETA?

Acompanhe com o painel de progresso

Abrir painel local

Abra outro terminal Ubuntu/WSL no computador que está coletando e execute:

cd ~/conferencia-eleicao-26Br-
scripts/coleta painel

Acesse http://127.0.0.1:8765/. A barra atualiza a cada 2 segundos com as seções concluídas, pendentes e falhas. Fechar o painel não interrompe a coleta.

O portal público não lê o andamento diretamente do seu computador. Na VPS, utilize túnel SSH em vez de abrir a porta na internet.

ASSISTENTE DE CONTRIBUIÇÃO

Vamos preparar sua primeira coleta

Reserve a zona por 24 horas e siga o roteiro para coletar, validar e enviar os resultados por Pull Request.

A reserva é compartilhada entre colaboradores no Cloudflare D1 e vence em 24 horas se não houver envio válido. O portal não executa a coleta nem recebe arquivos brutos; o envio continua por Pull Request.

1 Escolha a zona eleitoral

Municípios, códigos TSE e zonas são carregados do catálogo oficial das Eleições 2026. O sistema não usa códigos IBGE.

Carregando a lista de municípios e zonas eleitorais...

Depois de criar o Pull Request, informe o número aqui antes das 24 horas. O sistema valida o autor e os arquivos da zona. Uma zona em revisão não expira automaticamente.

2 Instale o coletor

Execute estes comandos no Linux, WSL (Windows) ou VPS, dentro de um terminal. O coletor requer Linux x86_64 (incluindo WSL), Git e Python 3.12. O primeiro bloco prepara o Python 3.12 usando uv.

5 Envie sua contribuição para revisão

        
Registre a zona automaticamente: execute o próximo comando no Ubuntu/WSL. Ele valida o pacote e acrescenta a zona ao arquivo site/dados/catalogo.json. O conteúdo JSON é um dado de cadastro, não deve ser colado no terminal.

        

        
Depois confira com git status e crie um Pull Request contendo apenas o JSON consolidado da zona e o catálogo atualizado. Se não tiver permissão de escrita no projeto, envie a alteração pelo seu fork.

        
Crie um Pull Request para a branch main do repositório oficial. Volte ao formulário e informe o número do PR em Registrar envio para revisão antes de vencer sua reserva. O sistema confere sua autoria e os arquivos da zona. Os resultados serão revisados antes de entrar no site público.

        
Privacidade: não envie BU, RDV, VSC, logs, diretórios raw/, arquivos de identificação pessoal nem credenciais. O único arquivo de resultados a publicar é o JSON consolidado.

      

    

  

  

    
Como auditamos

    
Compararemos os dois turnos por seção eleitoral, incluindo comparecimento, habilitação biométrica, votos válidos, brancos e nulos. Indicadores estatísticos servem para orientar análises, não para provar irregularidades por si só.

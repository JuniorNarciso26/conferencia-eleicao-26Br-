Contribuir com a coleta

Escolha uma zona eleitoral e receba um roteiro de coleta feito para ela. O portal preenche os códigos eleitorais e orienta você da instalação até o Pull Request.

A coleta roda no seu computador Linux/WSL ou VPS. A reserva de zonas e o envio automático ainda não estão disponíveis.

ASSISTENTE DE CONTRIBUIÇÃO

Vamos preparar sua primeira coleta

Em poucos passos você define a zona, prepara os comandos, valida os resultados e os envia para revisão via GitHub.

O site não executa a coleta, não reserva zonas automaticamente e não envia arquivos ao servidor nesta versão. O login GitHub é necessário para abrir o Pull Request, não para consultar os resultados.

Como auditamos

    
Compararemos os dois turnos por seção eleitoral, incluindo comparecimento, habilitação biométrica, votos válidos, brancos e nulos. Indicadores estatísticos servem para orientar análises, não para provar irregularidades por si só.

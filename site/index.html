O que explica a diferença de votos entre os turnos?

Cálculos automáticos para os dados selecionados.

Esta reconciliação mostra de quais categorias vêm as diferenças líquidas. Não identifica quais eleitores mudaram de voto. Comparações proporcionais são hipóteses, não previsões estatísticas.

Padrão de variação por seção eleitoral (urna)

As seções são analisadas individualmente. O resumo indica em quantas delas cada finalista teve a maior variação líquida entre os turnos; não identifica transferências individuais.

Percentuais: (votos no 2º turno − votos no 1º turno) ÷ votos no 1º turno × 100. Quando o valor inicial é zero, aparece “—”. A variação maior pode representar uma queda menor; a tabela não estabelece causa, transferência individual ou fraude.

Como funciona esta consulta

1. Escolha a localidade

Os filtros exibem somente zonas com pacotes de resultados efetivamente publicados.

2. Compare os dois turnos

Quando houver dados, visualize comparecimento, habilitação, votos válidos, brancos e nulos.

3. Confira o crescimento

A fórmula compara ganhos, reconcilia os totais dos dois turnos e mostra uma referência proporcional hipotética, com suas limitações.

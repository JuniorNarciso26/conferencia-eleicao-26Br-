Conferência Eleitoral 2026

Uma plataforma colaborativa para coletar, conferir e comparar resultados agregados dos Boletins de Urna publicados pelo TSE.

Ver projeto no GitHub Como contribuir
Plataforma colaborativa em desenvolvimento. O login e o envio de resultados ainda não estão disponíveis. Não são apresentados dados eleitorais simulados como oficiais.

Consultar

Em breve, qualquer pessoa poderá consultar zonas, seções, diferenças entre turnos e referências das fontes públicas, sem instalar programas.

Contribuir

Colaboradores poderão instalar o coletor GitHub em seus computadores, executar uma zona e enviar apenas resultados agregados para revisão.

Transparência da metodologia

Os dados serão processados localmente, com comparação de comparecimento, votos válidos, votos brancos, nulos e formas agregadas de identificação. O sistema não coleta o voto individual nem declara fraude a partir de diferenças estatísticas.

Ler metodologia
Projeto independente, sem afiliação ao Tribunal Superior Eleitoral.
